## 🚀 Proyecto destacado

**[GestionaPro](https://github.com/FavianRamos/GestionaPro)** — Sistema de gestión de ventas y productos con backend en Spring Boot y frontend en React.

- API REST completa (productos, categorías, usuarios, ventas) con autenticación JWT y roles (ADMIN / USER)
- 5 reportes de negocio: ventas por período, ingresos, productos más vendidos, ventas por categoría y stock bajo
- Tests unitarios, documentación con Swagger, y manejo global de excepciones
- Desplegado en producción: [API](https://gestionapro.onrender.com) · [Frontend](https://gestionapro-frontend.vercel.app) · [Repo Frontend](https://github.com/FavianRamos/gestionapro-frontend)
